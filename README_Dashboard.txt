# EV Market Dashboard

## Files
- `dashboard.html` — interactive dashboard page.
- Keep `EV_Market_Demo_Data.csv` in the same repository folder as `dashboard.html`.

## How to use
1. Open `dashboard.html` through GitHub Pages (recommended), not by double-clicking the HTML file.
2. The page loads `EV_Market_Demo_Data.csv` from the same folder.
3. Use the Registration year, EV type, Manufacturer, and City filters.
4. Existing `index.html` can remain the repository homepage. Open the dashboard at:
   `https://Omishajain24.github.io/ev-market-performance-insights/dashboard.html`

## Important data note
The current CSV contains synthetic demonstration records for practice. Dashboard values are illustrative, not official market statistics. Replace it with verified official Washington State EV Population data before making real-world claims.

The dashboard uses Chart.js and Papa Parse from public CDNs, so an internet connection is needed to load charts and parse the CSV.
